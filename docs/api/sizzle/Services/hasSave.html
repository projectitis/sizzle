Future<bool> hasSave({
  1. String? name,
})

Whether saved data exists under name, or under saveFile if name is omitted.

This does not validate it - a damaged save still reports true. Use it to decide whether to offer a "continue" option, and see load for telling a damaged save apart from no save at all.

Returns false if storage could not be queried, which is reported through log.

Implementation

static Future<bool> hasSave({String? name}) async {
  final resolved = _resolve(name);
  try {
    return await saveStorage.exists(resolved);
  } catch (e) {
    log.error('Save file "$resolved" could not be checked ($e)');
    return false;
  }
}

saveFile property

String get saveFile

The save file name used by load and save to persist player data between game sessions.

On native platforms this is a file in the application documents directory. On web it is the localStorage key, since web builds have no file system.

Defaults to defaultSaveFile. Set it before the first load or save to use a different name, or change it between calls to keep several independent save slots:

Services.saveFile = 'slot2.json';
await Services.save();

The name is used verbatim, so it must be valid for the platform: a file name on native, a localStorage key on web.

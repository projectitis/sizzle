FpsMeter

FpsMeter class

Measures the rate at which the engine actually presents frames.

This is the ground truth for "did the frame-rate limiting take?" - it reads FrameTiming.vsyncStart timestamps straight from the scheduler rather than inferring a rate from update calls, so it also catches frames dropped by the platform.

The meter keeps a fixed-size ring buffer of the last window frame intervals plus a running sum, so fps is O(1) and sampling allocates nothing per frame. It is inert until start is called; while stopped no timings callback is registered at all, so the cost of leaving metering off is exactly zero.

final meter = FpsMeter()..start();
// ... later ...
print(meter.fps);
meter.stop();

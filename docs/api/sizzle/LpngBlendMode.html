LpngBlendMode

LpngBlendMode enum

Photoshop blend modes, named in lowerCamelCase as they appear in a manifest. Only a subset maps to a native ui.BlendMode; the rest fall back to ui.BlendMode.srcOver when compositing (see uiBlendMode).

SaveStorage

SaveStorage class abstract

Where Services.save and Services.load keep their data.

Sizzle ships PlatformSaveStorage, which writes a file in the application documents directory on native platforms and a localStorage entry on web. Assign your own implementation to Services.saveStorage to put save data somewhere else - a cloud backend, an encrypted container, or MemorySaveStorage in tests.

Implementations signal failure by throwing. Services.save and Services.load catch, log and report the failure as false, so a backend does not need an error contract of its own.

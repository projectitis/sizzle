HwFrameRateProvider

HwFrameRateProvider class abstract

Seam for a platform plugin that can change the display's refresh rate.

Sizzle itself is pure Dart and ships no implementation, so Device.isHWFrameRateSupported is false until a companion plugin registers one into Device.hwFrameRateProvider. Implementations are best-effort: setHardwareFrameRate returning true only means the request was accepted, never that the panel actually changed. Sizzle verifies the outcome by measuring the real frame cadence.
